## Research

<table>
  <tr>
    <td valign="top">
      <b><a href="https://github.com/multimodal-ai-engineering/preflight-bench">What Does “Now” Mean to Your Computer-Use Agent?</a></b><br>
      <sub>Stale screenshots, page loads, and which check to run before a click · 2026</sub>
      <p>Computer-use agents act on screenshots that go stale mostly in the first second after a page opens, and a one-second wait prevents most of it. Where a check is still needed, pixels verify where the target is and a small model verifies what happened.</p>
      <a href="https://github.com/multimodal-ai-engineering/preflight-bench">Code and benchmark</a>

    <td valign="top">
      <b><a href="https://arxiv.org/abs/2604.12213">Modality-Native Routing in Agent-to-Agent Networks</a></b><br>
      <sub>A multimodal extension to the A2A protocol · 2026</sub>
      <p>When agents pass images and voice to each other as they are, instead of turning them into text first, task accuracy on a 50-task benchmark rose from 32% to 52%. The gain only appears when the receiving agent can reason over what it gets, and it costs 1.8 times the latency.</p>
      <a href="https://arxiv.org/abs/2604.12213">Paper</a> · <a href="https://github.com/multimodal-ai-engineering/modality-native-routing-a2a-protocol">Code</a>
    </td>
  </tr>
</table>

<table>

    <td valign="top">
      <b><a href="https://arxiv.org/abs/2603.25924">Good Scores, Bad Data: A Metric for Multimodal Coherence</a></b><br>
      <sub>Checking whether multimodal data agrees with itself · 2026</sub>
      <p>A model can score well while its inputs contradict each other. The Multimodal Coherence Score checks four kinds of agreement (identity, spatial, semantic and decision) without any downstream model, and tells you which one broke.</p>
      <a href="https://arxiv.org/abs/2603.25924">Paper</a>
